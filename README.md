# 🔬 Diode IV Characteristics Measurement System

🚀 A complete embedded system solution for measuring the **Current-Voltage (IV) characteristics** of diodes under both **Forward Bias** and **Reverse Bias** conditions.

This project combines:
- Custom Hardware Design
- Embedded Systems Programming
- PCB Development
- Python Desktop Application
- Serial Communication

---

# 📌 Project Overview

The system was designed to help laboratories, researchers, and chemical scientists rapidly test and analyze diode behavior under different operating conditions.

The device can:
- Measure Forward Bias IV characteristics
- Measure Reverse Bias IV characteristics
- Display instantaneous voltage/current values
- Analyze diode response under different light sources:
  - UV LEDs
  - IR LEDs
  - RGB LEDs

---

# 🛠 Hardware Design

## Microcontroller
- **ATMEGA32 MCU**

## Features
- Custom-designed PCB
- Analog measurement circuitry
- Serial communication interface
- External light source control
- Real-time data acquisition

# 💻 Desktop Application

A Python-based GUI was developed to communicate with the hardware through the Serial Port.

## GUI Features
- User-friendly interface
- Real-time measurements
- Live data visualization
- Forward/Reverse bias selection
- Instantaneous value monitoring
- Easy device communication

---

# 🔗 Communication

The system uses **Serial Communication (UART)** between:
- ATMEGA32 Microcontroller
- Python Desktop Application

This enables:
- Fast data transfer
- Stable communication
- Real-time monitoring
